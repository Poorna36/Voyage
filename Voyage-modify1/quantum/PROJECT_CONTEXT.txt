--------------------------------------------------------------------------------
1. MISSION OBJECTIVES AND OPERATIONAL CONSTRAINTS
--------------------------------------------------------------------------------
The system establishes automated, sub-pixel accurate (< 0.5 px target, < 1.0 px mandatory),
and spatially uniform correspondences between multi-modal lunar orbital datasets under
extreme operational challenges:
1. Illumination Disparity: Solar azimuth differences up to 180 deg; solar incidence
   angles up to 85 deg (deep, elongated shadows, grazing polar sunlight).
2. Scale Invariance (GSD Mismatch): Resolution disparities up to 17x (e.g., Chandrayaan-2
   OHRC at 0.25-0.32 m/px vs. TMC-2 at 5.0 m/px vs. LRO NAC at 0.5-1.0 m/px vs.
   LRO WAC at 100 m/px).
3. Topographic Relief: Parallax, oblique pushbroom perspective distortions, and severe
   topographic displacement across rugged lunar highlands and deep impact craters.
4. Multi-Modal Radiometry: Disparate detector transfer functions, non-linear phase-angle
   reflectance, and panchromatic vs. hyperspectral (IIRS 250 bands, 0.8-5.0 um) modalities.
5. Spatial Uniformity: Eliminates clustering of features along high-contrast crater
   rims; enforces wide baseline coverage across feature-sparse lunar maria.
6. Ground-Truth Absence: Natural sub-pixel GCPs do not exist on the Moon; human annotator
   variance (~0.8 to 1.5 px) exceeds sub-pixel targets, necessitating dual manual/synthetic
   validation protocols.

--------------------------------------------------------------------------------
2. PIPELINE MULTI-LAYER ARCHITECTURE
--------------------------------------------------------------------------------
The system decouples operational concerns into a 10-layer pipeline with two specialized
parallel tracks:

+--------+--------------------------------+-------------------------------------------------------------+
| Layer  | Functional Designation         | Core Responsibility                                         |
+--------+--------------------------------+-------------------------------------------------------------+
| L0     | Data & Geometry Ingestion      | PDS4 label parsing, ISIS3/SPICE initialization, ODE query   |
| L1     | Radiometric Normalization      | Shadow masking, dynamic range clipping, GSD pyramid         |
| L1.5   | Matcher Selection Model (MSM)  | 13-feature scene vector, LightGBM meta-dispatch (< 5 ms)    |
| L2     | Correspondence Engine          | Pluggable matchers: M0 SIFT, M1 RIFT2, M2 LightGlue, M3 YOLO|
| L3     | Spatial Uniformity             | Pre-match ANMS (SSC) + Post-match 8x8 grid density budget   |
| L4     | Geometric Verification         | DEGENSAC/MAGSAC++, Model Ladder, Polar Tile-wise models     |
| L5     | Sub-Pixel Refinement           | Local NCC/POC, 2D paraboloid fit, Tukey apodization         |
| L6     | Cartographic Product Export    | 16-bit GeoTIFF orthorectification, GCP CSVs, QC overlays    |
| L7     | Evaluation & Arbitration       | Held-out GT checkpoints, multi-strata scoring, audit        |
| Track  | Synthetic Ground-Truth Track   | Double-precision homography transforms, sensor noise, Hungarian|
| Track  | Hyperspectral IIRS Track       | Hapke photometric correction, 1.6 um band selection, < 80 m |
+--------+--------------------------------+-------------------------------------------------------------+

End-to-End Pipeline Data Flow:
[ISRO PRADAN PDS4] + [LRO NAC/WAC via Lunar ODE]
       |
       v  [L0: Data & Geometry] -> SPICE kernels, PairRecord in manifest.jsonl
       |
       v  [L1: Preprocessing]   -> valid_mask.png, GSD pyramid, tiles.geojson, meta.json
       |
       v  [L1.5: MSM Selector]  -> 13-dim feature vector -> LightGBM -> selector.json
       |
       v  [L2: Correspondence]  -> M0 SIFT, M1 RIFT2/LNIFT, M2 LightGlue, M3 Crater -> matches_raw.json
       |
       v  [L3: Spatial Filter]  -> ANMS (SSC) + 8x8 grid budget (max 5/cell, 250 tot) -> matches_selected.json
       |
       v  [L4: Verification]    -> F2 bounds checks, DEGENSAC, Model Ladder -> geometry.json
       |
       v  [L5: Sub-Pixel]       -> Local NCC/POC + 2D Paraboloid Fit -> matches_refined.json
       |
       v  [L6: Cartography]     -> Registered GeoTIFF, match_points.csv, QC diagnostics
       |
       v  [L7: Evaluation]      -> Eval partition RMSE, leaderboard.csv, arbitration.log

3. THE 15 ARCHITECTURAL INVARIANTS
--------------------------------------------------------------------------------
F01 - Dual-Stage Spatial Selection: Keypoint ANMS (SSC) pre-description paired with grid-density
      capping post-matching. Prevents feature starvation in low-contrast lunar maria.
F02 - Geometric Sanity Checking: In-domain boundary clipping (+-10 px buffer) and one-to-one
      mapping enforced on all matchers. Eliminates coordinate extrapolation.
F03 - Hierarchical Model Ladder: Evaluates Similarity (4 DoF) -> Affine (6 DoF) -> Homography
      (8 DoF) -> Tile-wise local models. Stops on RMSE <= 1.0 px. Prevents homography overfitting.
F04 - Lean Preprocessing for Learned Models: Deep models (LightGlue) receive minimal percentile
      clipping only. Heavy non-linear filtering perturbs deep neural representations.
F05 - Deep Shadow Validity Masking: Per-pixel binary mask from solar incidence and local gradient
      variance. Rejects correspondences in zero-information cast shadows.
F06 - Two-Tier Initialization: Strict NNDR filtering (Lowe ratio 0.75) for model seeds with relaxed
      pools for support. Maximizes inlier convergence in classical matching.
F07 - Calibrated Phase Correlation: Tukey/Gaussian apodization windows and 2D paraboloid peak
      interpolation. Blackman windows degrade lunar correlation peak sharpness.
F08 - Multi-Metric Acceptance Gate: Independent evaluation of RMSE, inlier ratio, and spatial
      coverage. Match count alone does not correlate with registration quality.
F09 - Geographic Partition Isolation: Partitioning by 10-degree geographic cells (geo_cell), never
      random pairs. Prevents spatial data leakage across train and test splits.
F10 - Product Provenance Integrity: Preserves original ISRO PDS filenames and binds per-date SPICE
      CK kernels. Prevents ingestion failure in ISIS3 and ASP toolchains.
F11 - Adaptive Winner Arbitration: Dynamic fallback escalation based on candidate inlier ratios
      and residuals. Guarantees pipeline output under challenging conditions.
F12 - Hyperspectral Module Decoupling: Photometric phase-angle correction and dedicated continuum
      band selection. Panchromatic intensity assumptions fail on multi-band IIRS data.
F13 - Spatial Coverage as Primary Metric: Enforces grid density variance and minimum cell occupancy
      gates (coverage >= 0.60). Critical for downstream DEM generation.
F14 - Quantitative Crater Gating: M3 branch executes only when crater density >= tau_c (3.0 craters/km^2)
      in both images and terrain is highland/polar. Prevents degenerate graphs in maria.
F15 - Disjoint MSM Meta-Training: Meta-model cross-validation strictly grouped by geographic cells.
      Prevents selector memorization of regional geology.

--------------------------------------------------------------------------------
4. ARCHITECTURAL DECISION RECORDS (ADRS D01 - D19)
--------------------------------------------------------------------------------
D01: Pluggable, Benchmark-First Matcher Architecture.
     - Decision: No single matcher is universal; run unified benchmark harness, arbitrate per stratum.
     - Rejected: Hardcoded single matcher (fragile), late ad-hoc selection (prevents objective scoring).
D02: SIFT (M0) as Fixed Baseline and Universal Fallback.
     - Decision: Difference-of-Gaussians + Lowe ratio (0.75) executes universally across all pairs.
     - Rejected: ORB (lowest inlier survival in maria), IntFeat (SIFT+ORB concatenation adds noise).
D03: SuperPoint with LightGlue (M2) as Primary Learned Matcher.
     - Decision: Attention-based transformer matching; adaptive depth/width; ~17 ms inference.
     - Rejected: SuperGlue (heavy compute, closed weights), LoFTR (no explicit point covariance).
D04: DEGENSAC and MAGSAC++ for Robust Geometric Verification.
     - Decision: Replaces standard RANSAC to detect dominant-plane degeneracy on flat lunar mare basins.
     - Rejected: Standard RANSAC (silent planar collapse), DOC/MGEO orientation filter (drops shadow points).
D05: Hierarchical Geometric Model Ladder.
     - Decision: Ascending DoF: Similarity (4) -> Affine (6) -> Homography (8) -> Local Tiles.
     - Rejected: Fixed global homography (overfits on planar/sparse scenes), Fixed affine (fails in relief).
D06: Dual-Stage Spatial Uniformity Enforcement.
     - Decision: Pre-match ANMS (SSC) on keypoints + post-match 8x8 grid density capping (max 5/cell).
     - Rejected: Pre-match only (fails for deep matchers), Post-match only (fails on initial starvation).
D07: Phase-Correlation Sub-Pixel Refinement with Tukey Apodization.
     - Decision: 32x32 window, Tukey alpha=0.50, 3-level pyramid, 2D paraboloid fit, secondary peak < 0.80.
     - Rejected: No refinement (> 0.5 px error), Blackman apodization (broadens correlation peak).
D08: Multi-Octave Scale-Space Extension for RIFT2 (M1).
     - Decision: Phase congruency with log-Gabor scale-space search bridges scale jumps up to 4x (and 17x).
     - Rejected: Unmodified RIFT (fails when GSD difference > 1.5x), HOPC (requires exact a-priori pointing).
D09: Dedicated Parallel Module for IIRS Hyperspectral Registration.
     - Decision: Isolated pipeline branch (configs/iirs_wac.yaml); Hapke correction; 1.6 um band; < 80 m error.
     - Rejected: Merging into panchromatic pipeline (gradient collapse, false correspondences).
D10: Deterministic Normalization over Generative Radiometric Synthesis.
     - Decision: Percentile clipping (2nd/98th), CLAHE, and statistical moment transfer.
     - Rejected: CycleGAN/cGAN (unstable training, risk of hallucinating topographic crater rims).
D11: Tile-Wise Local Model Partitioning for High Latitudes.
     - Decision: For |lat| > 55 deg or extreme relief (> 500 m), use overlapping 512 px tiles with Gaussian
       blending: w_T(x) = exp(-||x - c_T||^2 / (2 * sigma^2)), sigma = 256 px. Min 12 inliers/tile.
     - Rejected: Single global homography (diverges near lunar poles due to curvature/pushbroom angles).
D12: Geometric Checkpoint Metrics over Structural Image Similarity.
     - Decision: Primary evaluation uses ground-truth RMSE, inlier ratio, and spatial coverage. SSIM/PSNR
       are purely diagnostic.
     - Rejected: SSIM/PSNR as primary acceptance gates (high SSIM occurs on misaligned flat maria).
D13: Crater Density Gating for Crater-Geometry Matcher (M3).
     - Decision: Gated: executes only when crater density >= tau_c (3.0 craters/km^2) and terrain is highland/polar.
     - Rejected: Unconditional M3 execution (degenerate graph construction and false matches in maria).
D14: LNIFT Evaluation for Classical Fallback Promotion.
     - Decision: Evaluates LNIFT alongside RIFT2 for faster descriptor extraction on cross-sensor pairs.
D15: Placement of Matcher Selection Model at Layer 1.5.
     - Decision: Situated immediately after L1 preprocessing and before matcher dispatch.
     - Rejected: Post-match arbitration only (wastes 4x-10x compute), Pre-L1 (lacks texture/shadow features).
D16: LightGBM Gradient-Boosted Decision Trees for Meta-Classification.
     - Decision: Multi-class LightGBM on 13 features; CPU inference < 5 ms; handles small/medium sample sizes.
     - Rejected: Deep neural networks (overfitting on small planetary sets), Fixed heuristics (brittle).
D17: Dual-Threshold Confidence Routing and Safe-Mode Fallback.
     - Decision: P_max >= 0.65 -> single winner; 0.40 <= P_max < 0.65 -> top 2 matchers; P_max < 0.40 -> safe mode
       (executes full benchmark suite). Cuts compute > 50% while bounding RMSE delta <= 0.10 px.
     - Rejected: Strict argmax routing (causes catastrophic failures when confidence is split).
D18: Strict Geographic Cell Disjointness for Meta-Model Training.
     - Decision: Grouped by 10-degree geographic cells (geo_cell). Zero train/test overlap.
     - Rejected: Random pair-wise splits (causes spatial data leakage and optimistic evaluation bias).
D19: Formal Acceptance Criteria for Production Model Activation.
     - Decision: MSM remains inactive in production until passing all 8 criteria (AC1 through AC8).

6. DATA SENSORS, FORMATS & REFERENCE ACQUISITION
--------------------------------------------------------------------------------
Chandrayaan-2 Primary Sensors:
- OHRC (Optical High Resolution Camera): Panchromatic (450-900 nm), 0.25 - 0.32 m/px GSD, Level-2.
  File pattern: ch2_ohr_nrp_*_d_img_d18.zip (.img, .lbl, .xml). Primary source matching against LRO NAC.
- TMC-2 (Terrain Mapping Camera 2): Panchromatic Stereo, 5.0 m/px GSD, Level-2.
  File pattern: ch2_tmc_nrp_*_d_img_d32.zip. Secondary source matching against LRO WAC.
- IIRS (Imaging Infra-Red Spectrometer): Hyperspectral (0.8-5.0 um, 250 bands), 80 m/px GSD, Level-2.
  File pattern: ch2_iir_nrp_*_d_img_d32.zip (.qub). Parallel module matching against LRO WAC.

Reference Datasets (via Lunar ODE REST API or local crops):
- LRO NAC (Narrow Angle Camera): 0.5 - 1.0 m/px GSD. Product type CDRNAC4.
- LRO WAC (Wide Angle Camera): 100 m/px GSD. Product type CDRWAC4.
- LRO WAC 643 nm Global Mosaic: 100 m/px local GeoTIFF baseline.
- SELENE (Kaguya TC/MI) Moon Trek WMTS: Future fallback stratum.

ISRO PRADAN Ingestion Rules:
- Original ISRO filenames must NEVER be altered; sub-processes depend on tokenized timestamps and codes.
- Accompanying .xml files are parsed to extract: CENTER_LATITUDE, CENTER_LONGITUDE,
  SOLAR_INCIDENCE_ANGLE, SOLAR_AZIMUTH_ANGLE, MAP_SCALE.
- Ingestion supports chunked streaming (UPLOAD_CHUNK_SIZE_BYTES = 16 MB) to prevent RAM spikes.
- Differentiates between uint8 and 16-bit Big-Endian (SignedMSB2) rasters using numpy.memmap.
  Extracts 1024x1024 crops using <= 2 MB active RAM.

Reference Retrieval Fallback Hierarchy:
1. LRO NAC via Lunar ODE REST API (bounding box padded by k * sigma_pointing, k=3, sigma=1000m).
2. Local LRO WAC 643 nm global mosaic crop via GDAL.
3. SELENE Moon Trek WMTS.

Index 3: delta_solar_azimuth (float) -> |Delta az| in deg [0.0, 180.0]
Index 4: terrain_class_enc (int) -> 0 = highland, 1 = maria, 2 = polar, 3 = mixed

Index 8: src_texture_contrast (float) -> Mean local intensity std dev (8x8 window) in src

Index 10: src_mean_gradient (float) -> Mean Sobel gradient magnitude in src
Index 11: ref_mean_gradient (float) -> Mean Sobel gradient magnitude in ref

12. SYNTHETIC GROUND-TRUTH ENGINE & BENCHMARK TRACK
--------------------------------------------------------------------------------
Motivation:
Sub-pixel GCPs do not exist on the Moon. Human clicking variance (0.8 - 1.5 px) cannot validate
sub-pixel accuracy (< 0.5 px). The synthetic engine generates double-precision mathematical truth.

Mathematical Homography Engine:
H_true = T(c_x, c_y) * P * S(gamma_x, gamma_y) * K(s_x, s_y) * R(theta) * T(-c_x, -c_y)
Where:
- T(c_x, c_y): Translation to image center.
- R(theta): Planetary yaw rotation theta in [-180 deg, 180 deg].
- K(s_x, s_y): Scale factor s in [0.4, 3.0] representing GSD mismatches.
- S(gamma_x, gamma_y): Spacecraft trajectory shear matrix.
- P: Projective tilt vector representing off-nadir optical pointing.

Checkpoint Mapping & Partitions:
x_ref = H_true^-1 * x_src
Partitions:
- eval (70%): Reserved strictly for computing held-out RMSE, MedAE, pct_lt_0p5px.
- fit (20%): Used to verify model numerical conditioning.
- qc (10%): Injected with Gaussian jitter (sigma = 0.5 px) to simulate baseline human variance.

Physical Sensor & Radiometric Simulation:
1. Grazing Solar Illumination: Directional luminance ramps and dynamic shadow masks (up to 85 deg).
2. Photometric Non-Linearity: Power-law gamma curves (I_out = I_in^gamma, gamma in [0.7, 1.4]).
3. Pushbroom Electronics Noise: Poisson shot noise + Gaussian readout noise:
   I_noisy = Poisson(I * g) / g + Normal(0, sigma_n^2).
4. Point Spread Function (PSF): Sensor-specific MTF optical blurring.
Excluded: Non-physical warping, JPEG artifacts, and artificial color jitter are strictly prohibited.

Evaluation Assignment Rule:
Predicted correspondences are assigned to ground truth within a gating radius (r_max = 2.0 px)
using the Hungarian algorithm for strictly one-to-one assignment. Predictions outside r_max or
unassigned duplicates are counted as false positives.

Synthetic Stratification (30 to 60 pairs):
10 Equatorial Mare, 10 Equatorial Highland, 10 Polar Highland, 10 Multi-Scale GSD jumps (1.5x-4x),
10 Extreme Solar Azimuth Disparity (Delta az > 90 deg), 10 Projective Off-Nadir Perspective Tilt.

- Spatial Resolution: Source vs reference GSD with scale ratio indicators.
- Terrain Classification: Highland, mare, polar, crater floor with roughness coefficients.
- Quantitative Crater Density: Controlling matcher gating.
- IIRS Hyperspectral Profile: 250 bands (0.8 - 5.0 um); highlights 2.8 - 3.0 um water-ice absorption.
- Safe Landing Zone (SLZ) Index: Aggregates slope (< 10 deg), boulder hazard density, and registration confidence.

AddFilesModal (Mission Data Ingestion):
- Folder and Directory Bundle Ingestion via "Browse Folder" or drag-and-drop.
- Recursive entry traversal using HTML5 webkitGetAsEntry() and FileSystemDirectoryEntry.
- File badging: PDS-4 Label, Raw .IMG Raster, Archive Package (.zip), Calibrated Image (.cub).
- Role toggles: Source (Mission) vs Reference (Baseline).
- Live S1 -> S5 multi-stage ingestion ticker.
- 300-second network buffer for large orbital datasets.

Backend API Integration (services/api.ts):
- Dual operational modes: Live mode (FastAPI on http://localhost:8000) with automatic fallback
  to standalone mock mode when offline with zero UI interruption.
- Endpoints:
  - GET /api/health: Health check and hardware acceleration flags.
  - GET /api/datasets/: Catalog of source-reference pairs from manifest.jsonl.
  - GET /api/datasets/{pair_id}/crop: Memory-mapped sub-pixel raw .img crop with live stats.
  - POST /api/datasets/upload: Chunked streaming ingestion of user mission files.
  - GET /api/config/matchers: Matcher registry parameters and schema definitions.
  - POST /api/pipeline/run: Triggers pipeline execution for pair.
  - GET /api/metrics/{pair_id}: Retrieves final evaluation metrics and inlier checkpoints.
